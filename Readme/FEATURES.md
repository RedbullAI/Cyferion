# ScamGuard – Feature Planning

## Initial Feature Ideas (Brainstorming Phase)
These features were identified during early discussions.

### Core System
- Scam Detection Engine
- Active Protection Logic
- Role-Based Protection

### Family System
- Family Dashboard (Family Mode + Trusted Contacts)
- Quarantine System

### Social Layer
- Regional Language Support
- Scam Awareness Page

---

## v1 MVP Scope (Finalized)
Based on feasibility, time constraints, and hackathon goals, the following scope is finalized for v1.

### Included in v1
- Scam Detection Engine (rule-based)
- Role-Based Protection
- Guardian Dashboard (core)
- Logical Quarantine System
- Scam Awareness Page

### Partially Implemented in v1
- Active Protection Logic (alert-based only)
- Family Dashboard (no analytics, no advanced controls)

### Out of Scope for v1 (Planned for v2+)
- Full Regional Language Support
- Bank / UPI blocking
- Call and WhatsApp scam detection
